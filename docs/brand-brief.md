# ShadowPass — Brand Identity & Visual Design Brief

## 1. Brand Essence & Positioning
- **Name:** ShadowPass
- **Tagline:** Zero-Knowledge Private Allowlist Protocol on Midnight
- **Core Values:** Uncompromising Privacy, Mathematical Soundness, Seamless User Experience, Developer Rigor.

---

## 2. Color Palette & Design Tokens

| Token | Hex Value | Role | Meaning |
| :--- | :--- | :--- | :--- |
| **Midnight Obsidian** | `#030712` | Background Base | Deep space dark mode base |
| **Cyber Violet** | `#8b5cf6` | Primary Accent | Zero-Knowledge cryptography & elegance |
| **Emerald Verification** | `#10b981` | Success / Verified | Cryptographic proof validity |
| **Slate Surface** | `#111827` | Card & Panel BG | Glassmorphic containment |
| **Pure Ghost White** | `#f9fafb` | Primary Typography | High-contrast readability |
| **Muted Smoke** | `#9ca3af` | Secondary Typography | Subtle metadata and descriptions |

---

## 3. Typography & Motion Principles
- **Font Family:** Inter / System Sans-Serif for high clarity, JetBrains Mono for cryptographic hashes and addresses.
- **Motion:** Micro-animations on proof generation, glowing neon halos on verified status badges, smooth modal transitions via Framer Motion.
- **Accessibility:** High contrast ratios ($> 7:1$) for cryptographic outputs and error states.
